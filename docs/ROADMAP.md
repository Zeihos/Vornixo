# Дорожная карта VORNIXO

> **Актуальная ветка:** Alpha 0.21.0. Эта страница отражает планы, а не обещанные даты релизов.

[← На главную](../README.md)

## Что уже реализовано

- [x] Браузерный клиент и игровой сервер Node.js
- [x] Передвижение, добыча ресурсов и строительство
- [x] Независимые базы и волны зомби
- [x] Защитные сооружения, оружие и крафт
- [x] Отряды, командный чат и развитие базы
- [x] Игровые аккаунты и сохранения прогресса
- [x] Основные визуальные эффекты
- [x] Приостановка обороны при отсутствии защитников

## Следующие этапы

### Alpha 0.15.0 — синхронизация и ИИ противников

- [x] Список ресурсов отправляется при входе и после добычи или восстановления
- [x] Общие данные о постройках индексируются по базе за один игровой тик
- [x] Налётчики ищут генераторы поблизости, а остальные зомби не игнорируют баррикады
- [ ] Дополнительная проверка ограничений скорости и доступа
- [ ] Длительные реальные сессии с реконнектами и измерением задержек

### Alpha 0.16.0 — надёжность соединения

- [x] Автоматический повторный вход после обрыва в гостевой или зарегистрированный профиль (до 5 попыток)
- [x] Отключение неактивных TCP/WebSocket-соединений, освобождение слота и профиля
- [x] Регрессионные проверки повторного входа и ограничений сервера
- [ ] Длительные E2E-тесты в настоящих браузерах при нестабильной сети

### Alpha 0.17.0 — измерение нагрузки и обратное давление

- [x] Измерение времени игровых тиков и рассылок без сбора личных данных
- [x] Пропуск сетевых обновлений при переполненной очереди медленного клиента
- [x] Отключение клиентов с длительно заблокированной очередью
- [x] Автоматическая нагрузочная проверка: 16 игроков, 55 баррикад и 120 зомби
- [ ] Длительный стресс-тест через настоящие браузеры и на реальном хостинге

### Alpha 0.18.0 — сохранения и проверка длительных сессий

- [x] Запись игрового прогресса вскоре после отключения игрока с объединением частых записей
- [x] Атомарное обновление резервных JSON-копий без удаления последнего валидного бэкапа
- [x] Ограничение шага симуляции после длительной задержки процесса
- [x] Контроль числа автосохранений, ошибок записи и пропусков игровых тиков
- [x] Автоматическая проверка продолжительной четырёхпользовательской сессии и восстановления сохранений
- [ ] Полное испытание в реальных браузерах и на публичном хостинге

### Alpha 0.19.0 — независимость секторов и честные награды

- [x] Зомби выбирают цели среди игроков, находящихся в зоне назначенной базы
- [x] Защитные башни не атакуют врагов, у которых уже закончилось здоровье
- [x] Награда за уничтоженного зомби начисляется защитникам базы только один раз
- [x] Проверки: две базы с независимыми волнами, выход одного отряда, сохранение циклов, отсутствие повторных наград
- [ ] Проверка баланса и поведения игроков на границах секторов в реальной игре

### Alpha 0.20.0 — справедливые волны при нескольких базах

- [x] Не более 32 одновременно живых зомби на одну базу и до 160 на мир
- [x] Враг появляется вне территории другого маяка, не создавая случайных атак на соседей
- [x] Для старых переполненных сохранений один обычный враг из избыточной группы может освободить место под волну другой базы; боссы не удаляются
- [x] Автоматические тесты двух волн, глобального лимита, освобождения слота и совместимости сохранений
- [ ] Реальная проверка баланса высоких волн и пограничных ситуаций на сервере с игроками

### Alpha 0.21.0 — точный подсчёт наград и защита паузы

- [x] Убийства от шипов дают защитникам базы стандартную награду, как другие защитные сооружения
- [x] Смерть от продолжающегося горения засчитывается базе-источнику огня без повторных наград
- [x] Нельзя добывать золото и статистику, атакуя неподвижных зомби базы без подключённых защитников
- [x] Обычные атаки, гранаты и способности продолжают работать при активных защитниках
- [x] Добавлены регрессионные проверки шипов, горения, атак на паузе и активной обороны
- [ ] Балансировочные тесты оружия и обороны с несколькими реальными игроками

## Примечания

Порядок этапов и набор механик могут корректироваться по результатам тестов. Готовность к релизу определяется проверками игры, а не только номером версии.

Предложения по развитию можно оставить через [GitHub Issues](https://github.com/Zeihos/Vornixo/issues/new/choose).
