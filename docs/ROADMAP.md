# Дорожная карта VORNIXO

[← На главную](../README.md)

## Что уже реализовано

- [x] Браузерный клиент и игровой сервер Node.js
- [x] Передвижение, добыча ресурсов и строительство
- [x] Независимые базы и волны зомби
- [x] Защитные сооружения, оружие и крафт
- [x] Отряды, командный чат и развитие базы
- [x] Игровые аккаунты и сохранения прогресса
- [x] Основные визуальные эффекты
- [x] Приостановка обороны при отсутствии защитников
