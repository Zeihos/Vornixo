# Безопасность VORNIXO

## Текущий статус

VORNIXO находится на стадии **Alpha**, поэтому публичное размещение сервера с реальными аккаунтами без дополнительного аудита безопасности **не рекомендуется**.

## Как сообщить об уязвимости

Не публикуйте работающие эксплойты, секреты и данные игроков в открытых Issues.

Если GitHub предлагает кнопку **Report a vulnerability** во вкладке Security этого репозитория, используйте её для непубличного сообщения. Если такой возможности нет, сначала свяжитесь с владельцем репозитория через доступный приватный канал, указанный в его профиле, не раскрывая технические детали публично.

Для обычных ошибок интерфейса используйте [шаблон ошибки](https://github.com/Zeihos/Vornixo/issues/new/choose).

## Работа с данными

- Папка `data/` содержит игровые сохранения, профили и может содержать секреты сеансов. Она должна оставаться на сервере, а не в Git.
- Перед обновлением остановите сервер, сделайте резервную копию `data/` и проверьте восстановление.
- Для доступа из интернета настройте HTTPS/WSS, ограничения входа, журналирование и мониторинг.
- В истории ранних коммитов обнаруживались файлы сохранений. Удаление из `main` **не удаляет данные из истории Git**. Если они настоящие, необходимо оценить риск и отозвать скомпрометированные токены/сеансы; переписывать историю без плана миграции не следует.
