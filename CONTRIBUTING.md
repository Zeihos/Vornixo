# Участие в разработке VORNIXO

Спасибо за интерес к проекту! VORNIXO находится на стадии **Alpha 0.14.0**. Здесь можно сообщать об ошибках, предлагать улучшения и присылать исправления.

## С чего начать

1. Проверьте [существующие Issues](https://github.com/Zeihos/Vornixo/issues), чтобы не создавать дубликат.
2. Для ошибки используйте шаблон **«Сообщить об ошибке»**, для идеи — **«Предложить улучшение»**.
3. Для исправления создайте отдельную ветку от актуальной `main`.
4. Не меняйте игровую механику вместе с косметическими исправлениями без необходимости.
5. Перед Pull Request выполните:

```bash
npm test
npm run build:clean
npm run verify:clean
```

6. В PR напишите, что изменено, зачем и как проверялось. Приложите скриншот, если изменяли интерфейс.

## Стиль и структура

- Сервер: `server.js` (Node.js); браузерный клиент: `public/`.
- Игровые файлы и графика сообщества хранятся отдельно.
- Пользовательские сообщения, документы и обсуждения по возможности ведите **на русском языке**.
- Старайтесь не добавлять сторонние зависимости без реальной необходимости.
- Сохраняйте совместимость игровых данных либо описывайте способ миграции.

## Что нельзя коммитить

**Никогда** не добавляйте `data/`, `*.bak`, `.env`, токены, пароли, ключи, реальные профили или дампы базы. Не публикуйте чужие личные данные даже в логах и скриншотах.

## Права на исходный код

Проект публичен, но отдельная открытая лицензия пока не утверждена. Публикация репозитория **не равна разрешению** переиспользовать его код или распространять копии. Перед крупными внешними вкладами согласуйте условия с владельцем.

Вернуться к [главной странице](README.md).
