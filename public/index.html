Сначала соберите древесину и камень. Установите Маяк (2), затем разместите баррикады (3), турели (4), генераторы золота (5) и шипы (6). Для дальнего боя выберите арбалет (7), переключайте его на дробовик клавишей V; медстанцию (8) или криобашню (9). Улучшения Z, X, C оплачиваются золотом. Защищайте свой маяк во время его собственных ночных волн. Для разрядника нажмите 0, для миномёта и огнемёта откройте B. Достижения доступны через O, журнал обороны базы — через J. Каждый отряд строит собственную базу. У каждого маяка собственный таймер дня и ночи, номер волны и группа зомби. Командный чат доступен только участникам отряда. Крафт доступен через I, отряды — через T, исследования — через K, настройки — через P. Лес даёт больше древесины, горы — камня, болота — золота из кристаллов.
